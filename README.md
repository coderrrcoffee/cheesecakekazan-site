# Cheesecake Kazan — сайт-витрина

Статический сайт кондитерской с оформлением заказа в Telegram. Покупатель выбирает десерты, заполняет форму и нажимает «Оформить в Telegram» — открывается чат [@cheesecakezakaz](https://t.me/cheesecakezakaz) с готовым текстом заказа: состав, количество, сумма, вес, дата, адрес и пожелания.

Без CRM, базы данных и бэкенда.

## Превью

https://coderrrcoffee.github.io/cheesecakekazan-site/

## Деплой на Vercel

1. Add New Project → Import Git Repository.
2. Framework Preset: **Other**.
3. Build Command: оставить пустым.
4. Output Directory: `.`.
5. Deploy.

Сайт статический: `index.html` в корне, все ассеты в `assets/`.

## CMS для клиента

Карточки десертов лежат в `data/catalog.json` и редактируются через **Pages CMS**.
Клиент получает email-приглашение, заходит на [app.pagescms.org](https://app.pagescms.org)
и видит только раздел **«Витрина»**: название, описание, цена, вес, категория,
фото, плашка и переключатель «Показывать на сайте». Изменения коммитятся в GitHub
и через 30–60 секунд появляются на сайте. GitHub-аккаунт клиенту не нужен.

Схема полей — в `.pages.yml`. Клиент не может менять её и код.

Прямая ссылка в CMS: https://app.pagescms.org/coderrrcoffee/cheesecakekazan-site

Инструкция для клиента: [CMS.md](CMS.md).

## Что менять разработчику

`config.js` — бренд и настройки:

- `brand`, `contacts` — название, город, Telegram, телефон;
- `theme` — цвета;
- `delivery` — интервалы и условия;
- `form` — поводы и поля;
- `meta` — title/description и домен для превью ссылок.

`data/catalog.json` — карточки, если нужно поправить их напрямую или добавить
новую категорию. Фото лежат в `assets/photos/`.

## Важно

- Цены и веса в демо предварительные — подтвердить у клиента.
- Фотографии взяты из публичного Telegram-канала и используются для демонстрации.
- Кнопка в Telegram открывает чат с уже вставленным текстом, но сообщение отправляет сам покупатель.
- В Telegram Web/встроенном браузере текст может не подставиться — в модалке есть кнопка «Скопировать текст».
